title: "Review changes"
description: "Watch an agent's edits in the Code tile and send it line comments."
---

The Code tile shows what changed in a frame's folder. Comment on a line and the comment goes to
the agent as its next prompt.

<Prompt description="Paste this into your coding agent so it answers the review comments left on its work." actions={["copy","cursor"]}>
Work through the open review comments on this project's changes in Hivemind.

1. Run `hive review list --status open --json` in the project folder. If there are none, wait for the next one with `hive review watch --timeout 300` (it exits 4 when none comes in time; then tell me and stop).
2. For each comment, read it with `hive review show <id>`, open the file and line it names, and make the fix.
3. Run the project's tests or build to check the fix.
4. Reply with what you changed: `hive review reply <id> "<what changed>"`, then `hive review resolve <id> --summary "<how it was fixed>"`.
5. If a comment asks for something you disagree with or cannot do, reply saying why and leave it open.

At the end, run `hive review list --status open` again and tell me which comments are still open and why.
</Prompt>

<Steps>
  <Step title="Open the Code tile">
    Open the Code tile beside the agent (`3`) and switch it to **Changes**.
  </Step>
  <Step title="Read the diffs">
    Review each file's diff as edits land.
  </Step>
  <Step title="Comment on a line">
    Leave a comment on a line. The agent receives it as *Review comment on src/x.ts:42 …*, and
    fixes it.
  </Step>
</Steps>

Comments are kept in `.hivemind/review.json`, so these commands work with or without the app:

```bash
hive review list --status open
hive review show <id>
hive review reply <id> "fixed in 3f2c1a"
hive review resolve <id> --summary "how it was fixed"
hive review reopen <id>
hive review watch --timeout 300     # wait for the next comment
```

For a plan rather than a diff, an agent can ask you to approve it:
`hive ctl open-review --file plan.md` opens a review tile and waits for your decision.
