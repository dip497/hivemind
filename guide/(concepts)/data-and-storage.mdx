Hivemind keeps your data on your own computers: in two folders, and in your project's own
`.hivemind/` folder.

## The two folders

| Folder | Linux | macOS | Windows |
|---|---|---|---|
| Config folder | `~/.config/hivemind` | `~/.config/hivemind` | `~/.config/hivemind` |
| App data folder | `~/.config/hivemind` | `~/Library/Application Support/hivemind` | `%APPDATA%\hivemind` |

`XDG_CONFIG_HOME`, when set, replaces `~/.config`. `HIVEMIND_APP_DATA` names another app data
folder.

## What is where

| What | Where | Note |
|---|---|---|
| Settings | config folder, `settings.json` | shared by the app and `hive`. Every setting: [Settings](/settings) |
| Agent files | config folder, `agents/` | a project may add its own in `.hivemind/agents/` |
| Views, widgets and tools you install | config folder, `packages/` | each version's files in `packages/store/`, never changed; which version is in use and whether it is on in `packages/installed.json`. A project may add its own views in `.hivemind/views/` |
| Saved machines | config folder, `machines.json` | |
| Each workspace's layout: frames, tiles, viewport | app data folder, `workspaces/` | one file per project; shared workspaces in `shared/` |
| Window sizes and places | app data folder, `window-state.json` | |
| Saved screens | app data folder, `sessions/` | kept 30 days, so a screen survives a reboot |
| This device's keys | app data folder, `identity/` | never leave this computer |
| API tokens | app data folder, `grants.json` | only a hash of each token |
| Issues | your project, `.hivemind/` | Markdown, in your repository |
| Logs | app data folder | which file for what: [Logs and bug reports](/logs-and-bug-reports) |
| What updates changed in your data | each folder's `migrations/`: `ledger.json` and `backups/` | [When an update changes your data](/data-updates) |

A host keeps the same files in its own data folder on the server.

What a widget draws is never saved: it is drawn again each time.
