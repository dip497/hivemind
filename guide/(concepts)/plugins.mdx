A <Tooltip tip="Something you add to Hivemind: an agent, a view, a widget or a tool." cta="Glossary" href="/glossary#plugin">plugin</Tooltip> adds something to Hivemind. Your agents can make one, install one and open one while they work. The **Windows** view and the **Issues** tool ship with the app as plugins too.

<Diagram name="plugins-kinds" caption="Where each kind sits" />

- **View**: draws the whole workspace, in place of **Canvas** or **Windows**.
- **Tiles** inside it: an **agent tile** started from an agent file, a **terminal**, and a **tool tile** drawn by a tool.
- Each tile is lent to the view. Switching views keeps it running.
- **Widget**: a small card that floats above every view.

## The four kinds

| Kind | What it adds | Its file |
|---|---|---|
| **Agent** | a coding agent's own program, which Hivemind starts and reads | `agent.yaml` |
| **View** | a way of drawing the whole workspace | `hivemind-view.json` |
| **Widget** | a small live card on the <Tooltip tip="The view that lays your frames, tiles and widgets out on one endless surface." cta="Glossary" href="/glossary#canvas">canvas</Tooltip>, in every view | `widget.json` |
| **Tool** | a new kind of tile | `hivemind-tool.json` |

What each kind can reach, and why a tool you install starts switched off:
[Trust, permissions and privacy](/security-and-privacy).

## Add one

<Tooltip tip="The catalogue Hivemind installs agents and plugins from." cta="Glossary" href="/glossary#hivehub">HiveHub</Tooltip> is the catalogue the app and `hive` install from, over https. How each file is checked: [What you install from HiveHub](/security-and-privacy#what-you-install-from-hivehub).

1. Open **Settings → Plugins** and pick the **HiveHub** tab.
2. Pick a plugin. Its page shows **Read me** and **What it can do**.
3. Install it. A tool also needs switching on, on its page.

From a terminal:

```bash
hive plugins list                            # every plugin here, on or off
hive agents install claude                   # or: hive views, hive widgets, hive tools
hive plugins enable tool:dip497/worktrees    # a tool arrives switched off
hive plugins set view:@you/board columns all # a setting the plugin declares
```

Each plugin's page in **Settings → Plugins** has **Settings**, **Read me** and **What it can do**.

## Make one

To make your own, use **Add → Make your own…** in the toolbar, or **Add → Make your own** in
**Settings → Plugins**. Both write a prompt you hand to a coding agent.

From a terminal, each kind has a starter:

```bash
hive widgets new my-widget    # or: hive views new, hive tools new
```

Each starter includes `PROMPT.md`: the whole contract for that kind in one file. Write what you
want at the top, then hand the file to a coding agent.

## Agents can run a plugin's commands

A view, widget or tool can declare `"commands"` in its file and answer them in its code. An agent
lists and runs them while the plugin is open:

```bash
hive ctl plugin commands
hive ctl plugin call dip497/worktrees list
```
