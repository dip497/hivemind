# Writing the Hivemind guide

These are the pages of the user guide, served at https://hivemind.griiken.com/guide. Writing or
editing any of them, or a diagram on them, follows the `maintaining-docs` skill in
`.claude/skills/maintaining-docs/`. It covers where a page goes, one home per fact, the copy
rules, diagrams, the Markdown output for agents, and the checks to run before a PR.

The repository's `docs/` folder holds design notes, not this guide.
