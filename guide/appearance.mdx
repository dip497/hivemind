Change the look when you want other colours, a calmer background, or more contrast. Every change
applies at once and is saved for you.

<AgentPrompt description="Paste this into your coding agent to change Hivemind's look from the terminal." page="appearance">{`
Change how Hivemind looks, from the terminal, with the \`hive theme\` and \`hive config\` commands.

1. Show me the themes: \`hive theme list\`. Ask me which one I want, then run \`hive theme use <name>\`.
2. Before changing anything else, save the current look: \`hive theme export ~/hivemind-theme-backup.json\`.
3. For anything else I ask (blur, wallpaper, glass), read the value first with \`hive config get <dotted.path>\`, for example \`hive config get appearance.glass.blur\`. Then set it with \`hive config set <dotted.path> '<JSON value>'\`. The value is JSON: a number as is (\`12\`), text in double quotes inside single quotes (\`'"ice"'\`), \`true\` or \`false\`.
4. If \`hive config set\` refuses a value, show me its message. Do not edit the settings file by hand.

At the end, show the new values with \`hive config get appearance\`, and tell me that \`hive theme import ~/hivemind-theme-backup.json\` undoes it all.
`}</AgentPrompt>

<Tabs>
  <Tab title="In the app">
    <Steps>
      <Step title="Open Appearance">
        Open **Settings → Appearance**. Settings is the gear at the right end of the toolbar.
      </Step>
      <Step title="Pick a theme">
        Under **Theme**, pick a **Preset**. Then pick an **Accent**: the colour of buttons,
        selection and focus.

        Check: the whole window changes colour at once.
      </Step>
      <Step title="Set the background">
        Under **Workspace**, pick a **Background**: a moving wallpaper, a **Photo**, a **Video**, or
        **None**. **Media brightness** dims a photo or video. Turn off **Animate the background**
        for a still one.

        Check: the background shows behind your tiles.
      </Step>
      <Step title="Set the glass">
        **Glass** makes panels frosted, so the background shows through them. Set **Panel opacity**
        and **Blur**. Turn on **Frost tool content** to let the background show through terminals
        and editors too, and set its **Content tint**.

        Check: the Layers panel and toolbar look frosted over the background.
      </Step>
      <Step title="Add an overlay, if you like">
        Open **Overlays** and press **Add overlay**. Pick an image or video to place over the
        workspace. Transparent WebM, GIF and PNG files work.
      </Step>
    </Steps>
  </Tab>
  <Tab title="In a terminal">
    ```bash
    hive theme list                 # the presets
    hive theme use nord
    hive config set appearance.glass.blur 12
    hive config set appearance.wallpaper.kind '"ice"'
    ```

    Check: `hive config get appearance.glass.blur` prints `12`, and the open app has changed.
  </Tab>
</Tabs>

## Words on this page

| Word | Means |
|---|---|
| **Glass** | Frosted, see-through panels over the background. |
| **Overlays** | Images or videos placed over the whole workspace, such as a transparent animation. |
| **Tools in scene views** | How terminals and editors look inside a view you installed: **Use my theme** draws them as on the canvas; **Opaque** gives them a solid background. |

The background, glass and overlays show under the **Canvas** and **Windows** views. A view you
installed paints its own background.

## Share or keep your theme

Under **Advanced**, **Theme file** has **Copy JSON** and **Import…**. **Terminal colours** sets
the 16 terminal colours, the background, text, cursor and selection.

```bash
hive theme export my-theme.json
hive theme import my-theme.json
```

A guest who joins your workspace sees your theme, except your photo, video, overlays and fonts.

## Check it worked

- The window shows the theme you picked.
- `hive config get appearance.preset` prints its name.

## If it didn't

| You see | Do this |
|---|---|
| `hive config set` refuses a value | The value must be JSON: text in double quotes inside single quotes (`'"ice"'`). Its range is in the [Settings reference](/settings#appearance). |
| The text is hard to read over a photo | Lower **Media brightness**, or raise **Panel opacity**. |
| Something else | [Troubleshooting](/troubleshooting) |
