## The docs MCP server

These docs run their own MCP server. Connect it and your agent searches the docs when it needs
to, instead of guessing.

<DocsMcpCommands />

The page menu at the top of every page has **Connect to MCP** and buttons to add it to Cursor or
VS Code in one click.

## The whole docs as text

| File | Holds |
|---|---|
| <a href={`${docsUrl}/llms.txt`}>`/llms.txt`</a> | the list of pages, each with its one-line description |
| <a href={`${docsUrl}/llms-full.txt`}>`/llms-full.txt`</a> | every page in one Markdown file |

Add `.md` to any page's address for that page as Markdown, or use **Copy page** in the page menu.

## A prompt on each page

Where a page describes something you set up or do, it starts with a prompt: the exact
instructions to paste into Claude Code, Codex or any coding agent so it does the job on your
computer. Each one says what to check at the end, and asks you for anything only you can do, such
as a password, a sudo or a DNS record.

The page menu can also open the page in ChatGPT, Claude or Perplexity, to ask about it.
