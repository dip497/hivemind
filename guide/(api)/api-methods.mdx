Every method a token can call, from workspace API version `0.30`. A role allows its own methods and those of every role above it on this page.

<AgentPrompt description="Paste this into your coding agent to turn the methods on this page into a script that tells you when an agent waits on you." page="api-methods">{`
Using the methods on this page, write a script that watches my Hivemind workspace and tells me when an agent waits on me.

1. Ask me which workspace folder to watch. The script needs only the \`view\` role. Check Hivemind runs with the folder open: \`hive ctl agents\` must not exit 3.
2. Make a token: \`hive grant create waiting-watcher -w <folder> --role view --expires 30d --json\`. Keep the token out of this chat and out of git: put \`HIVE_DRIVE_TOKEN\`, \`HIVE_DRIVE_SOCK\` (the \`socket\` field) and \`HIVE_WORKSPACE\` in a git-ignored \`.env\`.
3. Connect and say hello as the Protocol page shows. Call \`agent.list\` with \`["<folder>"]\` and print each agent with its state and what it waits on.
4. Listen for \`agent.event\` events. When one has kind \`waiting\`, call \`agent.output\` with \`["<tile>", 20]\` and print those lines.
5. Use only methods this page lists under view; any other is refused with \`FORBIDDEN\`.
6. Run it, start an agent in the app that asks a question, and show me the script's output.

At the end, tell me how to stop the script and how to revoke the token: \`hive grant revoke <id>\`, the id from \`hive grant list\`.
`}</AgentPrompt>

`repo` is the workspace's folder. `tile` is a tile's id from `agent.list` or `agent.start`. Each call is sent as `{"id": 1, "method": "…", "params": [...]}` ([Protocol](/api-protocol)). The example column shows `params`.

## No role

No token can call the methods that commit, push, pull, stage or discard; write files; create or change issues and review comments; create or remove worktrees; let people in or change their roles; or make or revoke tokens.

That does not keep a program away from your files. With `terminals` it types into a shell, and with `agents` it starts agents. Either can run any command there.

Full parameters and results are in [`spec/workspace-api.md`](https://github.com/dip497/hivemind/blob/main/spec/workspace-api.md).
