In this tutorial you build a client that lists your agents, starts one, reads its reply, answers its questions and follows what happens. It takes about ten minutes.

## What you'll learn

- How a program says who it is, with a token.
- How to start an agent, read its reply and answer it.
- How to follow what your agents do, as it happens.

## Before you start

- Hivemind is running with your project open.
- Node 20 or newer (or Bun), or Python 3.9 or newer.
- A token for that project, made as in [Make an API token](/api-tokens). Use `agents` to follow every step here; `view` reads only.
- The token in your environment, never in your code:

```bash
export HIVE_DRIVE_TOKEN=hgr_…                          # from hive grant create
export HIVE_WORKSPACE=~/work/api                       # the project folder
export HIVE_DRIVE_SOCK=~/.config/hivemind/drive.sock   # the socket it printed
```

<Steps>
  <Step title="Install the SDK">
    <SdkInstall />

    The Python package uses only the standard library.
  </Step>
  <Step title="Connect">
    `connect()` reads the token, the workspace and the socket from the variables above. Without them, it uses this computer's app.

    <CodeGroup>
    ```ts TypeScript
    import { connect, ApiError } from "hivemind-api";

    const hive = await connect();
    // or: await connect({ token: "hgr_…", workspace: "/home/you/work/api", socket: "…/drive.sock" })
    console.log(hive.as);
    ```

    ```python Python
    from hivemind_api import connect, ApiError

    with connect() as hive:
        # or: connect(token="hgr_…", workspace="/home/you/work/api", socket="…/drive.sock")
        print(hive.as_)
    ```
    </CodeGroup>

    Check it worked: it prints your token's name, role and workspace:

    ```text
    { client: "dashboard", role: "agents", workspace: "/home/you/work/api" }
    ```
  </Step>
  <Step title="List the agents and start one">
    <CodeGroup>
    ```ts TypeScript
    const { agents } = await hive.agents.list();
    console.log(agents);

    const { tile } = await hive.agents.start({ program: "claude", prompt: "Run the tests" });
    ```

    ```python Python
    print(hive.agents.list()["agents"])

    tile = hive.agents.start({"program": "claude", "prompt": "Run the tests"})["tile"]
    ```
    </CodeGroup>

    Check it worked: a new agent tile opens in the app. `program` is an agent from `hive agents list`.
  </Step>
  <Step title="Read the reply, and answer a question">
    `agents.read` waits for the agent to finish replying. If it stops to ask you something, answer it.

    <CodeGroup>
    ```ts TypeScript
    const reply = await hive.agents.read(tile, { timeoutMs: 600_000 });
    if (reply.finalStatus === "waiting") {
      await hive.agents.answer(tile, reply.waiting!.since, { decision: "allow" });
    }
    console.log(reply.text);
    ```

    ```python Python
    reply = hive.agents.read(tile, timeout_ms=600_000)
    if reply["finalStatus"] == "waiting":
        hive.agents.answer(tile, reply["waiting"]["since"], {"decision": "allow"})
    print(reply["text"])
    ```
    </CodeGroup>

    | `finalStatus` | Means |
    |---|---|
    | `turn` | The reply is in `text`. |
    | `timeout` | It is still working. Read again. |
    | `working` | Read with `timeoutMs` 0: it is still working. |
    | `idle` | It was sent nothing since you last read it, and is not working. Send it a task. |
    | `waiting` | It asks you something. Answer with `agents.answer`: `allow` or `deny` a permission, or `{text}` for a question. |
    | `asleep` | It is asleep. |
    | `closed` | Its tile was closed. |

    Check it worked: the agent's tile turns amber while it waits, then goes back to work after your answer.
  </Step>
  <Step title="Listen to events">
    <CodeGroup>
    ```ts TypeScript
    const off = hive.on("agent.event", (repo, event) => console.log(event.kind, event.tile));
    // later: off();
    ```

    ```python Python
    off = hive.on("agent.event", lambda repo, event: print(event["kind"], event["tile"]))
    # later: off()
    ```
    </CodeGroup>

    | Event | Tells you |
    |---|---|
    | `agent.changed` | An agent appeared, changed or went. |
    | `agent.event` | An agent finished replying (`turnEnded`), started waiting on you (`waiting`), was answered, or reported. |
    | `status.changed` | An agent's status changed. |

    Check it worked: start an agent in the app. Your client prints `came`.
  </Step>
  <Step title="Handle errors">
    Every refusal is one `ApiError` with a `code`. `call` runs any method by name.

    <CodeGroup>
    ```ts TypeScript
    try {
      await hive.call("agent.start", [hive.workspace!, { program: "claude" }]);
    } catch (e) {
      if (e instanceof ApiError && e.code === "FORBIDDEN") console.log("this role may not start agents");
    }
    hive.close();
    ```

    ```python Python
    try:
        hive.call("agent.start", [hive.workspace, {"program": "claude"}])
    except ApiError as e:
        print(e.code)  # "FORBIDDEN"
    ```
    </CodeGroup>

    Check it worked: with a `view` token, it prints the refusal. The codes are listed on [Protocol](/api-protocol#error-codes).
  </Step>
</Steps>

<Note>
For Python with `asyncio`, import from `hivemind_api.aio`: `async with await connect() as hive:`. The methods are the same, awaited.
</Note>

## What the SDK gives you

Both SDKs have the same shape: `as` (Python `as_`), `workspace`, `call(method, params, timeout)`, `notice`, `on(event, fn)` that returns `off`, `closed` and `close()`. Helpers:

| Helper | Methods |
|---|---|
| `agents` | `list`, `since`, `start`, `read`, `send`, `answer`, `output`, `interrupt`, `close` |
| `frames` | `open`, `close` |
| `terminals` | `write`, `close` |

Everything else is on [Methods by role](/api-methods), through `call`.

**Other languages:** see [Protocol](/api-protocol) for the raw messages.
