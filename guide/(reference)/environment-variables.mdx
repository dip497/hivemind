This page lists the environment variables Hivemind reads, and the ones it sets in your tiles and
programs.

## The app and the hive command

| Variable | What it does |
|---|---|
| `HIVE_SETTINGS` | use this settings file instead of `~/.config/hivemind/settings.json` |
| `HIVEMIND_APP_DATA` | use this folder for the app's data: its token and the sockets it serves |
| `HIVEMIND_SAFE_MODE=1` | start with no added tool plugins loaded, after one broke the app |
| `HIVEMIND_SHELL_ENV=0` | tiles get the app's environment as it is, without reading your login shell's |
| `HIVEMIND_HIVE_NET` | the `hive-net` program to use, when it is not where the installer put it |
| `HIVE_BIN` | the `hive` program to copy to a [machine](/machines), when it is not the one beside the app |
| `HIVEMIND_PLUGIN_INDEX` | read the plugin catalogue from this address instead of HiveHub |
| `HIVE_WHO` | the name the activity log gives your `hive` commands; else your git name or user name |

## The installer

Set these before you run `install.sh` or `install.ps1`.

| Variable | What it does |
|---|---|
| `HIVEMIND_VERSION` | install this exact release, such as `v2026.10.3` |
| `HIVEMIND_CHANNEL` | `stable` or `nightly` |
| `HIVEMIND_APP_DIR` | where the app goes; default `~/.hivemind-app`, or `%LOCALAPPDATA%\hivemind` on Windows |
| `HIVEMIND_BIN_DIR` | where the `hive` and `hivemind` links go; default `~/.local/bin` (Linux and macOS) |
| `HIVEMIND_REPO` | the GitHub repository to download from; default `dip497/hivemind` |

## Programs that drive a workspace

A program of yours reads these to reach a workspace. See [Connect and call](/api-connect).

| Variable | What it holds |
|---|---|
| `HIVE_DRIVE_TOKEN` | the program's token. Keep it out of files git tracks. |
| `HIVE_DRIVE_SOCK` | where to connect; else the app's own |
| `HIVE_WORKSPACE` | which workspace to drive, when the token reaches several |

A tool's service gets `HIVE_DRIVE_SOCK`, `HIVE_DRIVE_TOKEN` and `HIVE_WORKSPACES` (the folders it
may drive, separated as in `PATH`). See [Write a tool](/tool-plugins#a-service-that-keeps-running).

## Set by Hivemind in an agent's tile

Hivemind sets these for an agent it can drive. Read them; do not set them yourself.

| Variable | What it holds |
|---|---|
| `HIVEMIND_TILE` | the id of the tile an agent runs in. If it is set, the agent can drive the canvas with `hive ctl`. |
| `HIVE_AGENT_ID` | the agent's id, which signs what it writes in the activity log |
| `HIVEMIND_GUIDE` | the command that prints how to drive other agents here: `hive guide agents` |
| `HIVE_DRIVE_SOCK` | where `hive ctl` connects |

The variables for your own network server's Docker setup are on
[Set up your own network server](/self-hosting).
