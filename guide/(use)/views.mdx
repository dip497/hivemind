## Switch views

1. Press ⌘E / Ctrl+E, or use the view switch in the toolbar.
2. Pick a view.
3. Check: the workspace redraws, and every tile is still running.

You can also pick a view with **Show as** in the Layers panel's title menu.

The view switch's list starts with the workspace you are in. **Switch workspace…** under its name
opens **Open recent**, where you pick another. A view that draws its own toolbar opens the same list.

## Canvas or Windows

| View | Best for |
|---|---|
| **Canvas** | seeing everything at once. Frames are coloured areas on one endless surface, and tiles sit inside them. |
| **Windows** | working in one or two tiles at a time. Tiles are tabs in panes you split, with the Layers panel beside them. Each person keeps their own layout. |

To split a pane in Windows, drag a tab onto a pane's edge, or press `⌘\` / `Ctrl+\`. Every Windows key
is on [Keyboard shortcuts](/keyboard-shortcuts).

### Find the agent that needs you

Each tab has a mark for what its tile asks of you: a pulsing triangle when it waits on you, a cross
when it failed, a diamond when it finished since you last looked, a ring when it wrote something you
have not seen, and a dot while it works. A pane with a tab that waits on you has an amber edge, and
the focused pane shows how many wait, as a button that takes you to the newest. A tile you already
looked at, here, on the canvas or in the Layers panel, is not marked again.

Press ⌥⌘A / Ctrl+Alt+A to go to the tile that most recently started waiting on you. It works from
anywhere, a terminal too, in every view.

1. Press ⌥⌘P / Ctrl+Alt+P, or choose the magnifier in a pane's bar.
2. Type part of a tile's name, its agent or its folder. Tiles that wait on you are first, then the
   ones you used most recently.
3. Press Enter, or a digit 1 to 9 before you type.
4. Check: the tile shows in its pane.

### Open a frame or a page as a layout

With tiles in two or more frames, a strip over the panes lists **All** and each frame, with how many
tiles it has and a mark when one of them needs you. Choose a frame to see only its tiles, laid out
side by side. Each layout keeps its own panes, so going back to **All** finds them as you left them.
When the workspace has pages, **By frame** switches the strip to **By page**.

### Type into several terminals at once

1. Show the terminals in panes side by side.
2. Press ⌥⌘B / Ctrl+Alt+B.
3. Check: each of their panes has a red edge, and its bar says in red how many terminals your
   typing goes to.
4. Press Esc, or choose **Stop**, to type into one again. Esc is not sent to the programs.

The Windows keys work when the view has focus, not a terminal: click a pane's bar first. Agents do
all of this with `hive ctl plugin call windows`; see the [CLI reference](/cli#hive-ctl-plugins).

<Note>
A Browser tile reloads its page once each time you switch views. Its tabs and history stay.
</Note>

## Install a view

<Tabs>
  <Tab title="In the app">
    1. Open **Settings → Plugins** and choose the **HiveHub** tab.
    2. Find the view and press **Install**.
    3. Check: press ⌘E / Ctrl+E and the view is in the list.
  </Tab>
  <Tab title="In a terminal">
    1. Run `hive plugins install @dip497/timeline`.
    2. Check: `hive plugins list --kind view` shows it with no load error.

    A package that opens with a view prints it, and the app offers to switch to it. The view
    brings the package's widgets the first time it shows: see [Packages](/packages).
  </Tab>
</Tabs>

These views are on [HiveHub](https://hivehub.griiken.workers.dev/), as `@dip497/<name>`:
`constellation` (your agents in 3D), `timeline` (today's work per agent), `agents-by-state`,
`workspace-map`, `agent-board` (notes agents pin) and `code` (your workspace as VS Code's
workbench: an explorer, tabs and split editors with live terminals, and each frame's code and
changes watched beside the agent writing them).

A view cannot read your files or use the network. It sees only what its permissions allow. The
app switches it off for the session if it misbehaves. To remove one, run
`hive plugins remove <id>`. To write your own, see [Write a view](/extension-authoring).

## Set the toolbar

The toolbar sits over the view. Each view's page in **Settings → Plugins** sets
**Toolbar → Display**: **Automatic**, **Top**, **Bottom**, **Collapsed** or **Off**.
**Customize actions** picks its buttons. With no toolbar, Settings is at the foot of the Layers
panel.

## If it didn't

| You see | Do |
|---|---|
| The view is missing from the switch | Run `hive plugins list --kind view` and read its load error. |
| The view shows nothing | It may need a permission. Open its page in **Settings → Plugins**. |
