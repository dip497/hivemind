## Switch views

1. Press ⌘E / Ctrl+E, or use the view switch in the toolbar.
2. Pick a view.
3. Check: the workspace redraws, and every tile is still running.

You can also pick a view with **Show as** in the Layers panel's title menu.

## Canvas or Windows

| View | Best for |
|---|---|
| **Canvas** | seeing everything at once. Frames are coloured areas on one endless surface, and tiles sit inside them. |
| **Windows** | working in one or two tiles at a time. Tiles are tabs in panes you split, with the Layers panel beside them. Each person keeps their own layout. |

To split a pane in Windows, drag a tab onto a pane's edge, or press `⌘\` / `Ctrl+\`. Every Windows key
is on [Keyboard shortcuts](/keyboard-shortcuts).

<Note>
A Browser tile reloads its page once each time you switch views. Its tabs and history stay.
</Note>

## Install a view

<Tabs>
  <Tab title="In the app">
    1. Open **Settings → Plugins** and choose the **HiveHub** tab.
    2. Find the view and press **Install**.
    3. Check: press ⌘E / Ctrl+E and the view is in the list.
  </Tab>
  <Tab title="In a terminal">
    1. Run `hive plugins install @dip497/timeline`.
    2. Check: `hive plugins list --kind view` shows it with no load error.
  </Tab>
</Tabs>

These views are on [HiveHub](https://hivehub.griiken.workers.dev/), as `@dip497/<name>`:
`constellation` (your agents in 3D), `timeline` (today's work per agent), `agents-by-state`,
`workspace-map` and `agent-board` (notes agents pin).

A view cannot read your files or use the network. It sees only what its permissions allow. The
app switches it off for the session if it misbehaves. To remove one, run
`hive plugins remove <id>`. To write your own, see [Write a view](/extension-authoring).

## Set the toolbar

The toolbar sits over the view. Each view's page in **Settings → Plugins** sets
**Toolbar → Display**: **Automatic**, **Top**, **Bottom**, **Collapsed** or **Off**.
**Customize actions** picks its buttons. With no toolbar, Settings is at the foot of the Layers
panel.

## If it didn't

| You see | Do |
|---|---|
| The view is missing from the switch | Run `hive plugins list --kind view` and read its load error. |
| The view shows nothing | It may need a permission. Open its page in **Settings → Plugins**. |
