Read what an agent changed as it works, and send it line comments it fixes as its next task.

<AgentPrompt description="Paste this into your coding agent so it answers the review comments left on its work." page="review">{`
Work through the open review comments on this project's changes in Hivemind.

1. In the project folder, run \`hive review list --status open --json\`. If there are none, wait for the next one with \`hive review watch --timeout 300\`. It exits 4 when none comes in time; then tell me and stop.
2. For each comment, read it with \`hive review show <id>\`, open the file and line it names, and make the fix.
3. Run the project's tests or build to check the fix.
4. Reply with what you changed: \`hive review reply <id> "<what changed>"\`. Then run \`hive review resolve <id> --summary "<how it was fixed>"\`.
5. If you disagree with a comment or cannot do it, reply saying why and leave it open.

Check: \`hive review list --status open\` shows only the comments you left open. Tell me which ones and why.
`}</AgentPrompt>

## Comment on an agent's changes

1. Select the agent's frame and press **3** to open the Code tile.
2. Switch the Code tile to **Changes**.
3. Check: each changed file shows its diff, and it updates as the agent edits.
4. Select a line and leave a comment.
5. To send it, press **Send review to Claude** for every comment, or **→ claude** on one.
   Then pick the agent in **Send to agent**.
6. Check: the agent receives it as its next task, starting *Address this review comment*.

Comments are kept in `.hivemind/review.json`, so an agent can also read them itself. These
commands work with or without the app:

```bash
hive review list --status open
hive review show <id>
hive review reply <id> "fixed in 3f2c1a"
hive review resolve <id> --summary "how it was fixed"
hive review reopen <id>
hive review watch --timeout 300     # wait for the next comment
```

## Approve an agent's plan

An agent can ask you to approve a plan before it starts the work.

1. The agent runs `hive ctl open-review --file plan.md`.
2. Check: a **Plan review** tile opens beside the agent, and the agent waits.
3. To ask for changes, select text in the plan or hover a block, and comment. Then press
   **Request changes**.
4. To go ahead, press **Approve plan**.
5. Check: the agent's `open-review` command prints your decision, and the agent carries on.

The agent waits up to 24 hours unless it passes `--timeout`.

## If it didn't

| You see | Do |
|---|---|
| **3** does nothing | The frame has no project folder. Select a frame bound to a folder. |
| The agent never gets your comment | Send it again and pick that agent in **Send to agent**. |
| `hive review watch` exits 4 | No comment came in time. Run it again, or with a longer `--timeout`. |
