## Before you start

- Your own [network server](/self-hosting), with a public name and a trusted certificate. The Docker setup serves the page at `/phone/`.
- This computer is on that server: `hive network doctor` prints a `✓` line for every relay.

If the server does not serve the page yet, the **Phone browser** tab says so and offers **Set it up with an agent**.

## Pair your phone

<Steps>
  <Step title="Show the code">
    On the computer, open **Settings → Connect**, press **Connect**, and pick the **Phone browser** tab.

    Check: a QR code shows, with the server's name under it.
  </Step>
  <Step title="Scan it">
    Scan the QR code with the phone's camera. Tap **Connect** on the page that opens.

    Check: both screens show the same three words.
  </Step>
  <Step title="Confirm it is you">
    Press **It's me — the words match** on the computer, then **Yes** on the phone.

    Check: the phone shows **Home**, with your agents.
  </Step>
</Steps>

Add the page to your home screen. It then opens at once, offline too, and updates itself.

| Screen | Does |
|---|---|
| **Home** | What needs you first, then working agents, pinned tiles, then every project. Hold or swipe a row to **Stop** or **Close**. **+** starts an agent, with up to four photos. |
| An agent's chat | The conversation, with each tool use folded into one line. The round button sends, or stops the agent's reply. |
| A question | **Allow** / **Deny**, the options to tap, or **Approve** for a plan. Or type your own answer. |
| Terminal | Fitted to the phone, with **Esc**, **Tab**, arrows, **^C** and **Fit**. |
| **Views** | Installed views marked for phones, including ones that show your [widgets](/widgets). |

The first answer counts, from the phone or the computer.

### Who sizes a terminal

<Diagram name="phone-terminal-size" caption="Whoever typed last sets the size" />

- Opened on the phone → **phone size**.
- Phone size → **desktop size**: a key typed on the desktop, **Fit** turned off, the terminal closed, or the page hidden.
- Desktop size → phone size: a phone key while **Fit** is on, pressing **Fit**, or showing the page again.
- Whoever typed last sets the size. **Allow**, **Deny** and choosing an option are not typing.

## If it didn't

| You see | Do |
|---|---|
| The **Phone browser** tab offers **Set it up with an agent** | The server does not serve the page yet. Set it up: [network server](/self-hosting). |
| The page does not open on the phone | `https://<address>/phone/manifest.webmanifest` must answer 200, with a trusted certificate. |
| The three words differ | Press **Deny**. Someone else used the code. Make a new one. |

More in [Troubleshooting](/troubleshooting).
