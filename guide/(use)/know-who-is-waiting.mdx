When an agent stops to ask you something, Hivemind turns its tile amber, counts it on the bell
and can notify you. This page shows each signal and how to tune it.

<AgentPrompt description="Paste this into your coding agent to have your phone notified whenever an agent needs you." page="know-who-is-waiting">{`
Set up Hivemind on this computer so my phone gets a push notification whenever an agent needs me.

1. Check Hivemind is installed: \`hive --version\` prints a version.
2. Ask me whether I use ntfy (the free app at \`https://ntfy.sh\`) or another service that takes a plain-text POST. For ntfy, suggest a long random topic name and tell me to subscribe to it in the ntfy app on my phone. Wait until I say I have.
3. Run \`hive push set https://ntfy.sh/<topic>\`. To also hear when an agent finishes replying, add \`--events input.requested,turn.ended\`.
4. Run \`hive push test\`. Ask me whether the phone showed "test push from hivemind".
5. Run \`hive push status\` and show me where pushes go.

At the end, tell me the topic, which events push, and that \`hive push off\` stops it.
`}</AgentPrompt>

## The signals

| Signal | Where | What it tells you |
|---|---|---|
| Amber | an agent's tile, its row in the Layers panel, its frame | this agent <Tooltip tip="An agent waiting for a person: a permission question, a choice, a plan to approve, or a supervised worker's request. Its tile turns amber." cta="Glossary" href="/glossary#needs-you">needs you</Tooltip> |
| A second line | an agent's or a terminal's row in the Layers panel | what it waits for, or what its screen last showed |
| The bell | top of the <Tooltip tip="The list beside the canvas of your projects, frames and tiles. ⌘B / Ctrl+B shows or hides it." cta="Glossary" href="/glossary#layers-panel">Layers panel</Tooltip> | how many agents need you |
| A toast | inside the app | an agent needs you, finished, or failed |
| An OS popup | your desktop | the same, when the app window is not in front |
| A spoken line | your screen reader | the same as a toast, also for the tile you are in |
| A push | your phone | an agent needs you, even when you are away |

Amber always means a person is being waited on. The other colours are on [Agent states](/agent-states).

## Read what each row says

Under the name of each agent and terminal in the Layers panel, a second line says what its screen
last showed, such as `214 tests passed`. When an agent needs you, the line says what for, in amber:

| The line | What the agent waits for |
|---|---|
| a tool and its command, such as `Bash: npm test` | your permission to run it; only the command's first line shows |
| **Asks:** and a question | your answer |
| **Plan ready for review** | your review of its plan |
| **Permission**, **Question**, **Approval** or **Blocked** | that, in a word: its agent tells no more |

Claude keeps its own conversation, so its row shows a line only while it waits for you.

A terminal's line leaves out its prompt and what you type there, so it shows what the last command
printed. A few rows are the exception:

- A question a command waits on, such as `Overwrite b? [y/N]` or a password prompt, is the line on
  Linux. On macOS and Windows it is left out with the prompt.
- A prompt that takes two rows shows its top row, unless your shell marks where its prompt starts,
  as shell integration does (the OSC 133 marks).
- A question your shell asks itself, such as `read -p`, is left out with the prompt.

To choose which rows show a line, open the Layers panel's **View** menu, then **Lines**:
**All** (every agent and terminal), **Needs you** or **Off**.

## Jump to the next one

1. Press the bell at the top of the Layers panel.
2. Check: the next agent that needs you is selected and shown.
3. Answer it in its tile: choose an option, type a reply, or press **Approve plan** for a plan.

Press the bell again for the next one. Its tooltip says how many are left.

## Choose what notifies you

1. Open **Settings → Notifications**.
2. Under **Notify me about**, switch on what you want: **Needs you**, **Finished** or **Failed**.
3. Under **Delivery**, choose **In-app toasts**, **Native OS popups**, or both. **In-app toasts**
   also covers what a screen reader says.
4. Check: the next agent that needs you shows a toast.

**Do Not Disturb** mutes **Finished** and **Failed** between two times you set.
**Needs you** still reaches you.

## Snooze a row

To hide an agent from the Layers panel for a while, open its row's ⋮ menu and choose **Snooze**:
**30 minutes**, **1 hour**, **2 hours** or **Tomorrow at 9:00**.

A snoozed row waits under **Snoozed**. It comes back early as soon as its agent needs you.
**Wake now** in the same menu brings it back at once.

## Get a push on your phone

<Tabs>
  <Tab title="A push app (ntfy)">
    1. Install ntfy on your phone and subscribe to a topic only you know.
    2. On the computer the agents run on, run `hive push set https://ntfy.sh/<topic>`.
    3. Run `hive push test`.
    4. Check: your phone shows **test push from hivemind**.

    By default a push goes out when an agent needs you. To also hear when an agent finishes
    replying, add `--events input.requested,turn.ended`. `hive push off` stops it.

## Check it worked

- Start an agent and ask it to do something that needs permission.
- Its tile turns amber and the bell shows **1**.
- With notifications on, a toast or popup names the agent.

## If it didn't

| You see | Do |
|---|---|
| An agent asks something but its tile never turns amber | See [Troubleshooting](/troubleshooting). |
| No toast or popup | Check **Settings → Notifications** is on, and **Needs you** with it. |
| `hive push test` fails | The URL is wrong, or the computer cannot reach it. Run `hive push status`. |
