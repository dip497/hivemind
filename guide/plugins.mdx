## The four kinds

| Kind | What it adds | Where it sits | What it can touch | Its file |
|---|---|---|---|---|
| **Agent** | a coding agent's own program, which Hivemind starts and reads | a tile | everything you can: it runs in your terminal | `agent.yaml` |
| **View** | a way of drawing the whole workspace | the window, instead of **Canvas** | only what its permissions allow: no files, no network | `hivemind-view.json` |
| **Widget** | a small live card | on the <Tooltip tip="The view that lays your frames, tiles and widgets out on one endless surface." cta="Glossary" href="/glossary#canvas">canvas</Tooltip>, in every view | only what its permissions allow: no files, no network | `widget.json` |
| **Tool** | a new kind of tile | a tile, beside terminals | everything you can: it runs inside the app | `hivemind-tool.json` |

## Why tools start switched off

A view and a widget run in a sandbox. They see only what their permissions allow, and they can
never read a file or reach the network.

A tool runs inside the app, with your access to files, programs and logins. An agent runs in your
terminal. So a tool you add starts switched off, and you turn it on yourself. If one breaks the
app, start Hivemind with `HIVEMIND_SAFE_MODE=1 hivemind`: no added tool loads.

Installing from <Tooltip tip="The catalogue Hivemind installs agents and plugins from." cta="Glossary" href="/glossary#hivehub">HiveHub</Tooltip> checks every file against the checksum HiveHub recorded. It shows what the plugin may do before anything is copied.

## Add one

1. Open **Settings → Plugins** and pick the **HiveHub** tab.
2. Pick a plugin. Its page shows **Read me** and **What it can do**.
3. Install it. A tool also needs switching on, on its page.

From a terminal:

```bash
hive plugins list                            # every plugin here, on or off
hive agents install claude                   # or: hive views, hive widgets, hive tools
hive plugins enable tool:dip497/worktrees    # a tool arrives switched off
hive plugins set view:@you/board columns all # a setting the plugin declares
```

Each plugin's page in **Settings → Plugins** has **Settings**, **Read me** and **What it can do**.

## Make one

To make your own, use **Add → Make your own…** in the toolbar, or **Add → Make your own** in
**Settings → Plugins**. Both write a prompt you hand to a coding agent.

From a terminal, each kind has a starter:

```bash
hive widgets new my-widget    # or: hive views new, hive tools new
```

Each starter includes `PROMPT.md`: the whole contract for that kind in one file. Write what you
want at the top, then hand the file to a coding agent.

## Agents can run a plugin's commands

A view, widget or tool can declare `"commands"` in its file and answer them in its code. An agent
lists and runs them while the plugin is open:

```bash
hive ctl plugin commands
hive ctl plugin call dip497/worktrees list
```
