Make a <Tooltip tip="A secret a program of yours uses to drive a workspace, with one role." cta="Glossary" href="/glossary#token">token</Tooltip> when a program of yours should drive a workspace: a dashboard, a script, an orchestrator.

## Before you start

- Hivemind is running with the workspace open, or `hive host` serves it.
- You know what the program does, so you can pick the smallest role. See [Choose a role](#choose-a-role).

## Make the token

<Tabs>
  <Tab title="In the app">
    <Steps>
      <Step title="Open API access">
        Open the workspace, then **Settings → API access**.
      </Step>
      <Step title="Name it and pick a role">
        Under **New token**, name what uses it, for example *my dashboard*. Pick what it may do.
      </Step>
      <Step title="Create and copy">
        Press **Create token**, then **Copy**. The token is shown this once.
      </Step>
    </Steps>

    A token made in Settings reaches the workspace in that window and never expires.
  </Tab>
  <Tab title="In a terminal">
    To make a read-only token that lasts 30 days, run:

    ```bash
    hive grant create dashboard -w ~/work/api --role view --expires 30d
    ```

    It prints the token first, shown once (long lines wrapped here):

    ```text
    hgr_…
    dashboard may view in api, until 2026-11-17T09:00:00Z
      (`hive grant revoke 1a2b3c4d5e6f`).
    It connects to ~/.config/hivemind/drive.sock and says
      {"hello": {"token": "<this token>", "workspace": "<the folder>"}}.
    ```

    | Option | Means |
    |---|---|
    | `<name>` | What the program is called. It shows in the token list and the audit log. |
    | `-w`, `--workspace` | A workspace it may drive: its folder, name or id. Repeat it for more. |
    | `--role` | `view`, `edit`, `terminals` or `agents`. Without it, `agents`. |
    | `--expires` | How long it lasts: `12h`, `30d`. Without it, until you revoke it. |
    | `--json` | Prints `{grant, token, socket}`. |
  </Tab>
</Tabs>

<Note>
Hivemind keeps only a hash of each token. A lost token cannot be shown again, so make a new one.
</Note>

## Choose a role

<Roles />

A dashboard needs `view`; an orchestrator that starts agents needs `agents`. A call the role does not allow is answered `FORBIDDEN` and never runs. The full list is on [Methods by role](/api-methods).

## Check it worked

To see your tokens, run:

```bash
hive grant list
```

```text
1a2b3c4d5e6f  dashboard  view  /home/you/work/api  expires 2026-11-17T09:00:00Z  last used never
```

**Settings → API access** shows the same list, with when each token was last used.

## Revoke a token

Press **Revoke** in **Settings → API access**, or run it with the id from `hive grant list`:

```bash
hive grant revoke 1a2b3c4d5e6f
```

Revoking closes the program's connections at once. An expired token closes them at that moment too.

## If it didn't work

| What you see | Fix |
|---|---|
| `hive ctl` exits 3 | Neither the app nor `hive host` is running. Open the workspace with `hivemind <folder>`. |
| `FORBIDDEN` on hello | The token is wrong, revoked or expired, or does not reach that workspace. Make a new one. |
| `BAD_REQUEST` on hello | Name the workspace's folder, and open it in the app first. |

More in [Troubleshooting](/troubleshooting).
