# @hivemind/hub

The hub kit: the plugin index format and its reader, and the checks a plugin folder must pass. The Hivemind app, `hive` and HiveHub all use it, so a hub lists only what the app installs.

How the index works, what happens to an entry the app cannot read, and how a hub depends on the kit: https://hivemind.griiken.com/guide/hub-index
