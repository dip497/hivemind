Hivemind runs coding-agent CLIs alongside terminals, editors, file trees, and diffs.
Group tools by repository, git worktree, or SSH host. Issues live as Markdown files
in your repository.

- [Install and start a workspace](getting-started/)
- [Control agents with the CLI](agent-workflows/)
- [CLI reference](cli/)
- [Build a workspace view](extension-authoring/)

These docs follow the development branch. **Views, the view SDK, and the new settings
commands are development previews.** Check `hive --help` for commands available in
your installed version.

For coding agents, use [the documentation index](../llms.txt). Each guide is also
available as plain Markdown under `markdown/`.
