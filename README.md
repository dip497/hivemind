<h1 align="center">Hivemind</h1>

Hivemind runs your agent CLIs side by side, and your agents write the widgets, tools and views
you work with. MIT licensed, on your own computer, with no account.

## Install

Linux x86_64 and macOS on Apple Silicon:

```bash
bash <(curl -fsSL https://hivemind.griiken.com/install.sh)
```

Windows x64, in PowerShell:

```powershell
irm https://hivemind.griiken.com/install.ps1 | iex
```
